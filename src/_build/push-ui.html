第 6 步 · 把几项功能合到一起，再打一枚（只在你电脑上）把上面勾中的那几条功能分支合到一条本地分支上，再从合好的那份代码打一枚安装包。这条本地分支永远不进远程。
第 7 步 · 推到远程，请 main 合并（发 PR）两件事分开按，各推各的分支，互不牵连。
7A · 这一轮的改动（推上去，请 main 合并）这一颗走的是这一轮那条分支，一路八步：同步 → 起分支 → 把改动提交到本地 → 查有没有把本机地址带出去 → 推 → 建 PR。合并由你在 GitHub 网页上亲手点。
7B · 勾中的那几项功能（各自一条分支，各发一份合并申请）上面第 4 步勾的是"装进包里测"，这里勾的是"推到远程留个档"。没勾的一项都不推，留在本地。
第 8 步 · 你在 GitHub 网页上亲手合并小助手不合并：你核对 diff、亲手点 Squash and merge，并勾上合并后删掉远程那条分支。这颗按钮只是去问一句：合进去没有。
第 9 步 · 本地收尾再同步一次 main，然后把这一轮发完的那条分支从本地删掉（还没合进 main 的一条都不删）。
第 10 步 · 打包发版（版本号取 main 上最新那一笔）这颗要三样都齐：本地改动都提交完了、这份代码站在 main 或合好的那份代码上、这一轮那条分支已经合进 main。插件各家的版本号、标记、安装包一起落。
